# Dataset Files

Place the following CSV files in this directory:

1. **movies.csv** - Movie information (movieId, title, genres)
2. **ratings.csv** - User ratings (userId, movieId, rating, timestamp)
3. **tags.csv** - User tags (userId, movieId, tag, timestamp)
4. **links.csv** - External links (movieId, imdbId, tmdbId)

These files can be obtained from the [MovieLens dataset](https://grouplens.org/datasets/movielens/).

The recommended dataset is **MovieLens Latest Small** (ml-latest-small).
